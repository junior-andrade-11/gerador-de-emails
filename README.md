# 📧 Gerador de E-mails — Setor de Compras

Ferramenta web criada para gerar rapidamente e-mails padronizados utilizados no processo de Compras.

## 🎯 Para que serve

Reduz o tempo gasto redigindo e-mails recorrentes, além de ajudar na padronização das mensagens e na redução de erros.

## ⚙️ Funcionalidades

- Pedido de compras
- Solicitação de compra via Mercado Livre
- Solicitação de pagamento
- Sugestão automática de assunto
- Validação de campos obrigatórios
- Botão para copiar o texto
- Abertura direta no Outlook
- Assinatura personalizada
- Tema claro/escuro
- Salvamento automático do formulário

## 🛠️ Tecnologias

`HTML` `CSS` `JavaScript` `localStorage`
